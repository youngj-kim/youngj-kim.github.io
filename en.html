About

My background is in automotive navigation map data operations, where I have worked with road networks, search and routing quality, and pre/post-deployment validation. I focus less on building software for its own sake and more on defining the QA object, review criteria, and repeatable validation steps that make map data operations easier to inspect and explain.

This portfolio connects navigation data QA automation with public-data map services. Kakao and NAVER QGIS plugins support desktop review and file-based route comparison; the safety-zone monitor and Military Family Benefit Map turn public data into searchable maps and change-review workflows. Domain knowledge, QA criteria, and verifiable deliverables guide the work.

QGIS Kakao Roadview Bridge

A QGIS plugin connecting Kakao Map and Roadview with location review, place search, driving routes, and guidance-point inspection in one map QA workflow.

Implemented Scope
  • Bidirectional map position/zoom synchronization and Roadview position/direction layers
  • Kakao Local search and Mobility routes with up to five waypoints, avoidance and vehicle options
  • Route/guidance history import and export to GeoPackage, GeoJSON, Shapefile, and GPX
  • Dock and external browser modes with adjustable map/Roadview layout
Validation / Remaining Work

Targets QGIS 3.34+ and QGIS 4 / Qt 6. The exact 3.34 runtime remains unverified; fare comparison in development candidate 1.2.2 is a separate validation scope.

Safety Zone Change Monitoring System

A data operations project preserving raw and normalized police safety-zone API snapshots, detecting additions, deletions, attribute and geometry changes, and supporting review through notifications and a map dashboard.

Implemented Scope
  • Polygon, facility Point, integrated zone groups, and change-event history
  • Supabase PostgreSQL/PostGIS and GitHub-hosted runner; six scheduled chunks at 20-minute intervals from 09:00 to 10:40 KST
  • Province-level GeoJSON and lazy loading, nationwide search, repeated-change timelines, and KR/EN views
  • OSM/Kakao maps, Roadview, change-triggered Slack/Telegram notifications, and run history
  • Full data refresh on success, run-history refresh on failure, fetch/rebase push retries, and Pages deployment after monitoring
Validation / Remaining Work

Standard-link and NGII road-centerline candidate review remains in local PostGIS/QGIS. Confirmed automatic road matching and the success of individual production runs require separate verification.

Military Family Benefit Map

A web map for searching official Military Manpower Administration benefit facilities and Ministry of National Defense off-base marts, connecting public data with facility search, directions, and change review.

Implemented Scope
  • Region, 22 business categories and benefit-type filters, marker clustering, and viewport search
  • Benefit details, contacts, original sources, Kakao/Naver directions, and mobile map/list views
  • Official mart records preserved separately from address-geocoded coordinates
  • Monthly official-source comparison at 09:00 KST on the first day, reports, candidate branches, draft PRs, and Telegram notifications
  • Empty-response, duplicate-ID and over-25% drop checks before reviewed data updates
Validation / Remaining Work

The MMA snapshot was collected on 2026-10-16; the MND list is dated 2026-04-28. Geocoded positions are distinguished from official coordinates. Benefits and operating conditions should be checked with the original source and facility.

Multi-Provider Navigation Route QA

The Kakao plugin now opens Kakao and Naver GPKG route histories for A/B review on a map and comparison table, advancing the previous plan into an implemented file-based comparison workflow.

Implemented Scope
  • Supports EPSG:4326 GPKGs containing kakao_route_history or naver_route_history
  • Distance, duration, query timestamps, and B−A differences
  • Warnings for endpoint differences over 20 m or different waypoints
  • Blue solid A / orange dashed B route overlays and overlay removal
Validation / Remaining Work

Development candidate 1.2.2 adds toll and estimated taxi fare comparison. Times/fares are query-time estimates; automatic missing-guidance/detour detection and a web comparison dashboard remain future work.
