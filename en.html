QGIS PLUGIN / DESKTOP GIS02

Kakao QGIS Bridge

Bring QGIS, Kakao Map, and Roadview into one workspace. Reduce repetitive map-review steps, from location checks to route and fare comparisons.

PythonQGISKakao APIs
Scope & validation ＋
v1.3 · available on QGIS Plugins
  • Synchronized map movement and zoom with Roadview position and direction
  • Place search, driving routes, up to five waypoints, and GIS exports
  • Distance, duration, toll and estimated taxi-fare comparison for Kakao / NAVER GPKG routes

Checks are documented for Windows QGIS 3.44 / 4.2 environments. The declared minimum QGIS 3.34 has not been runtime-tested. API keys are stored unencrypted in user settings.

Different routes. A shared QA lens.

Overlay Kakao and NAVER route histories and compare distance, duration, and fares. Turn provider results into reviewable GIS data.

GeoPackageQGISRoute QA
