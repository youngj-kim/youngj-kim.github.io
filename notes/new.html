FIELD NOTES / WRITE

새로운 기록을 시작하세요.

글 작성과 저장은 GitHub 웹 편집 화면에서 진행합니다.

  1. 아래 버튼을 눌러 GitHub에 로그인합니다.
  2. 파일 이름 끝의 new-note를 영문 주제로 바꾸고, 템플릿의 제목·분류·요약·본문을 작성합니다.
  3. Preview 탭에서 Markdown 표시를 확인합니다.
  4. Commit changes에서 main 브랜치에 저장하면 자동으로 배포됩니다. 새 브랜치에 저장했다면 PR을 main에 병합해야 게시됩니다.

GitHub에서 새 글 작성 ↗

이 버튼은 GitHub 편집 화면만 엽니다. 사이트 방문자에게 저장소 쓰기 권한을 주지 않으며, 실제 저장은 권한이 있는 GitHub 계정만 할 수 있습니다.

발행과 수정

published: true는 발행, published: false는 사이트에서 숨김입니다. 이 저장소는 공개되어 있으므로 숨긴 글도 GitHub 파일과 변경 이력에서는 볼 수 있습니다. 비공개 초안은 로컬에서 보관해 주세요.

기존 글 하단이 아닌 제목 아래의 GitHub에서 수정 링크로 수정할 수 있습니다. 변경한 내용은 저장 후 다음 배포에 반영됩니다. 날짜를 미래로 설정한 글은 다음 사이트 빌드 전까지 게시되지 않습니다.

자세한 Markdown·이미지 사용법은 작성 안내에서 확인하세요. 배포 결과는 GitHub Actions에서 볼 수 있습니다.
