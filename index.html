About

저는 자동차 내비게이션 지도 데이터 운영 현장에서 도로 네트워크, 검색, 경로 안내, 배포 전후 검증과 관련된 문제를 다뤄왔습니다. 단순한 기능 구현보다 실제 QA 업무에서 반복적으로 발생하는 확인 절차를 정의하고, 이를 GIS 기반 도구와 데이터 처리 흐름으로 개선하는 데 강점이 있습니다.

최근에는 QGIS Python plugin, Kakao/Naver route comparison, Open API 기반 보호구역 변경 감지, PostgreSQL/PostGIS 공간 데이터 관리처럼 navigation data QA와 직접 연결되는 프로젝트를 진행하고 있습니다. AI coding tools는 필요한 경우 보조적으로 활용하지만, 핵심은 도메인 지식, QA workflow 설계, 데이터 검증 기준을 실제 도구로 옮기는 일입니다.

Navigation Data Operations

도로 네트워크 유지보수, 현장/로드뷰 기반 확인, 지도 데이터 배포 전후 검증 경험.

Map Data QA

검색, 경로 안내, VOC 이슈 분석, 데이터 변경 영향 확인을 위한 실무형 QA 접근.

GIS Workflow Design

QGIS, PostGIS, Open API를 활용한 반복 QA 업무 자동화와 공간 데이터 분석 도구 설계.

Projects

Route QA Planned Extension / In Progress

Multi-Provider Navigation Route QA System

QGIS Kakao plugin의 확장 방향으로, Kakao와 Naver route 결과를 비교해 경로 품질과 안내 차이를 분석하는 QA workflow를 설계하고 있습니다.

Planned Scope
  • Kakao / Naver route geometry 비교
  • distance, duration, turn-by-turn guidance 차이 분석
  • route divergence, missing guidance, abnormal detour 후보 확인
  • QGIS plugin을 desktop analysis tool로 활용
  • exported route comparison result를 향후 web dashboard에서 시각화하는 방향 검토
Current Position

아직 완성된 제품이 아니라 QGIS 기반 분석 도구에서 출발하는 확장 프로젝트입니다. 구현된 범위와 계획된 기능은 별도로 구분해 관리할 예정입니다.
