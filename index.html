Kakao QGIS Bridge

QGIS와 카카오 지도·로드뷰를 하나의 작업 공간으로. 위치 확인부터 경로·요금 비교까지, 반복되는 지도 검수의 흐름을 줄입니다.

PythonQGISKakao APIs
구현 범위와 검증 사항 ＋
v1.3 · QGIS 저장소 배포
  • 지도 이동·확대·축소 동기화와 로드뷰 위치·방향 표시
  • 장소 검색, 자동차 경로, 최대 5개 경유지와 GIS 파일 내보내기
  • 카카오·네이버 GPKG 경로의 거리·시간·통행료·예상 택시요금 비교

Windows QGIS 3.44 / 4.2 계열에서 확인된 범위가 문서화되어 있습니다. 선언된 최소 지원 버전인 QGIS 3.34는 실행 미검증입니다. API 키는 사용자 설정에 암호화 없이 저장됩니다.

현재 맵퍼스에서 자동차 내비게이션 분야의 해외사업을 담당하고 있습니다. OEM 운영과 공간 데이터에 대한 이해를 바탕으로 글로벌 비즈니스에 참여합니다.

약 9년간 자동차 내비게이션 지도 데이터 운영, 도로 네트워크 유지보수, 배포 검증, VOC 이슈 분석, OEM 지원, HD Map / ADAS 데이터 지원 업무를 수행했습니다.

어떤 데이터를 확인할지, 무엇을 기준으로 판단할지, 다시 확인할 수 있는 근거를 어떻게 남길지. 도메인 경험을 바탕으로 QA 기준을 세우고 QGIS, PostGIS, Open API로 실제 사용할 수 있는 도구를 만듭니다.
