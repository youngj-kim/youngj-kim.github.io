About

저는 자동차 내비게이션 지도 데이터 운영 현장에서 도로 네트워크, 검색, 경로 안내, 배포 전후 검증과 관련된 문제를 다뤄왔습니다. 개발 자체보다 중요한 것은 QA 대상, 판정 기준, 반복 확인 절차를 명확히 정의하고 이를 실무에서 사용할 수 있는 도구로 정리하는 일이라고 보고 있습니다.

현재 포트폴리오의 중심은 navigation data QA 자동화입니다. QGIS Kakao Roadview Bridge는 현장 확인과 지도 화면을 연결하는 desktop QA tool이고, Safety Zone Change Monitoring System은 공공 보호구역 데이터의 변화, 운영 이력, 지도/Roadview 기반 검수 흐름까지 연결하는 운영형 데이터 프로젝트입니다. AI coding tools는 보조적으로 활용하지만, 핵심은 도메인 지식과 QA workflow 설계를 실제 검증 가능한 산출물로 만드는 과정입니다.

GIS Workflow Design

QGIS, PostGIS, Open API를 활용한 반복 QA 업무 자동화와 공간 데이터 분석 도구 설계.
